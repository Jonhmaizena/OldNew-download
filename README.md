## English

OldNew turns an old phone into a lighter, more modern device:

- **Home screen** with eras (80s, 90s, 2000s, Modern, Futuristic) and styles. The phone's original apps stay in a folder. You can go back to the original home screen any time (drawer → "Go back to the original home screen").
- **Social networks in one tap:** YouTube, X, Instagram, Facebook, Reddit and TikTok open in a light built-in browser that remembers the last page. If a site won't run on your phone, it suggests a free alternative app from F-Droid.
- **Built-in apps:** Weather (with hourly rain for the week), Clock with alarm, J.FM radio, Contacts, Email, Calendar, Notes, Files, Transfer (Bluetooth and NFC, no internet), Documents (docx, xlsx, pptx), Gallery with photo editor and OldIA (direct answers from web search).
- **Private browser with its own engine** (Android 5+): Gecko, the engine of Firefox, comes inside the app, so websites open even if the phone's "Android System WebView" is old. You can switch to the system engine in the browser menu › Engine.
- **Privacy:** no account, ads, statistics or trackers. Nothing is sent to us. The app asks before reading anything on the phone, shows a short notice on every access and keeps a log only on the phone.
- **Updates itself:** every 2 days (on Wi-Fi by default) it checks this page for a new version, downloads it and only installs it if the signature is the same as the installed OldNew. On Android 12+ this can happen without any screen; otherwise a notification asks you to tap to install. You can turn it off in OldNew Settings › Updates.
